# Learning OS (IDE Agent-First)

Hệ điều hành học tập cá nhân hóa vận hành trực tiếp bởi IDE Agent.

## Hướng dẫn Bắt đầu Nhanh (Quick Start)
1. Đặt tài liệu học tập (sách, bài báo, ghi chú) vào thư mục `inputs/books/` hoặc `inputs/papers/`.
2. Mở chat IDE Agent và nói: *"Học tài liệu inputs/books/<tên_tệp>"*.
3. Agent sẽ lập lộ trình 80/20 tại `learning-space/courses/<slug>/00_overview/syllabus.md`.
4. Nói *"Vào bài học"* để bắt đầu tương tác chủ động (Socratic, Active Recall, Web Labs).
5. Làm bài tập hoặc thực hành Web Lab, bấm *"Sao chép kết quả Lab"* và dán vào chat để nhận phản hồi tức thì.

## Cấu trúc Thư mục
- `inputs/`: Chứa toàn bộ tài liệu nguồn gốc (Chỉ đọc).
- `learning-space/courses/`: Nơi lưu trữ các khóa học, bài học Markdown, sơ đồ và Web Labs.
- `.agents/`: Toàn bộ Agent Kit (Rules, Skills, Workflows, Templates, Scripts kiểm định).
