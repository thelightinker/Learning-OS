# Hòm Thư Tiếp Nhận Nguồn Duy Nhất (Single Drop Zone)

Chào sếp! Đây là **nơi duy nhất** sếp cần thả tài liệu nguồn vào khi muốn chuẩn bị xây dựng khóa học mới.

## 📌 Hướng dẫn Sử dụng Cực Đơn Giản
1. **Thả tài liệu vào đây:** Bất kỳ file nào (sách `.txt`/`.md`/`.pdf`, bài báo, ghi chú thô, transcript video...). Sếp **không cần phân loại** hay đắn đo xem nên đặt vào đâu.
2. **Kích hoạt Agent:** Mở chat và nói một câu ngắn gọn:
   > *"Chuẩn bị khóa học từ inbox"* hoặc *"Quét tài liệu nguồn"*
3. **Agent tự động làm phần còn lại:**
   - Quét toàn bộ file trong hòm thư, tính băm SHA-256 để bảo toàn tuyệt đối bản gốc (không chỉnh sửa, không copy nhân bản).
   - Tự động nhận diện cấu trúc, đếm dòng, bóc tách đề mục.
   - Phân loại tài liệu vào đúng Archetype (Sách dài $\rightarrow$ Verbatim Slice; Bài báo $\rightarrow$ Paper Deep-Dive; Ghi chép $\rightarrow$ Synthesis).
   - Đề xuất chiến lược khóa học: Tên khóa học, danh sách module dự kiến, phương thức học tối ưu.
