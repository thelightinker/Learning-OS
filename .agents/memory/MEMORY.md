# Learning OS — Long-Term Memory & Pattern Exemplars

## 1. Core Architectural Patterns
- **IDE Agent-First Ecosystem:** The file system is the single source of truth and database.
- **Mechanical Source Slicing:** Zero-LLM token copying via line offsets prevents hallucinations and guarantees byte-for-byte source fidelity.
- **Offline Self-Contained Interactive Labs:** HTML/SVG simulations with error boundaries and clipboard bridge receipts.

## 2. Pedagogical Best Practices
- Socratic checkpoints with active recall and self-explanation.
- Dual-tier assessment (zero-token automated client-side check + embedded rubric qualitative evaluation).
- 4-stage spaced retrieval schedule (1d -> 3d -> 7d -> 14d -> MASTERED).

## 3. Context Budget Management
- Dual-file persistence (`progress.md` snapshot <= 200 lines + append-only `progress-log.md`).
- Bounded token footprint (< 4.000 tokens per operational turn).
